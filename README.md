# Portfólio de Análise de Dados

Projetos selecionados para demonstrar análise exploratória, preparação de dados, métricas de negócio, visualização e testes estatísticos, com foco em oportunidades de **Analista de Dados Júnior**.

## Projetos

1. [Vendas de videogames](projetos/vendas-de-videogames/README.md) — desempenho por plataforma, gênero e região para apoiar decisões comerciais.
2. [Mercado de táxis](projetos/mercado-de-taxis/README.md) — empresas, destinos e duração de corridas em Chicago.
3. [Marketing e retorno](projetos/marketing-e-retorno/README.md) — LTV, CAC e ROI por origem de aquisição.
4. [Dashboard Tableau](projetos/tableau/README.md) — tendências de vídeos por categoria, data e país.
5. [Sazonalidade hoteleira](projetos/sazonalidade-hoteleira/README.md) — demanda mensal, ADR e testes estatísticos.

## Ferramentas

Python, pandas, matplotlib, seaborn e SciPy nos notebooks; Tableau no dashboard. Cada projeto lista as ferramentas verificadas nos arquivos.

## Dados e reprodução
